# 果蝇探险

用 FlyWire 全脑接线图驱动的果蝇，在随机生成的地图里自己找吃的：
脑内指南针、转向电路、复眼视觉、嗅觉，还有会记住“哪种气味跟着苦”的蘑菇体学习。

**在线打开：** https://xiangyangssss-del.github.io/fly-explore/

## 装到手机主屏幕（像 App 一样打开，断网也能用）

- **iPhone**：用 Safari 打开上面的链接 → 分享 → 「添加到主屏幕」
- **安卓**：用 Chrome 打开 → 菜单 → 「安装应用」（或「添加到主屏幕」）

页面里右上角「ⓘ 说明」有完整介绍：哪些是从接线图算出来的、哪些是按行为学论文写的规则，以及实测结果。

## 出处

- 神经数据：FlyWire 全脑接线图（Codex 公开数据）。Dorkenwald et al. 2024；Schlegel et al. 2024（Nature）。
  全脑模型做法参照 Shiu et al. 2024（Nature）。其余文献见页面内「说明 → 数据来源」。
- 应用图标里的果蝇照片：「Портрет дрозофилы」（Portrait of fruit fly），Грибков Михаил 摄，
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，来自
  [维基共享资源](https://commons.wikimedia.org/wiki/File:Портрет_дрозофилы.jpg)；裁成方形，右半边改成了数字线框。
